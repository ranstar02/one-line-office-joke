A tiny deterministic program that writes one joke about office life — a single line, 113 characters, about the meeting that should have been an email:

> Our 'quick sync' has a 47-slide deck, no agenda, and ends with action items for a meeting about the action items.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

This writes the joke to `entry.txt` in the output directory (default `/output/entry.txt`).

Deterministic: no randomness, no network, no secrets — the same line every run.
